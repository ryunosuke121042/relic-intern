# 残っている決めごと・次にやること

## 検証

- 判定する人数（「崩れた人が何人出たら判定するか」「最初に何人に声をかけるか」）

## アプリ

- 自分で追加した予定（勉強以外）も、崩れの判定で「できた日」に数えるか
- 2日以上開かなかったとき、前日より前の日もスワイプで確認するか（今は前日だけ確認し、それより前は「できなかった」として扱う）
- 追加した予定を消す機能を付けるか
- ブラウザ版にだけある機能（スワイプでの確認、予定の追加、日付を進めるデモ）を完全版にも入れるか
- GitHubへの保存（方法：アクセストークンを渡す、または Claude Code を使う）
