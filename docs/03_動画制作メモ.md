# 動画制作メモ（TikTokテストマーケティング）

目的：ユーザー拡大ではなく、提供価値を探索する。
流れ：① 仮説設計 → ② 素材あつめ → ③ 動画制作

## ① 仮説設計（済み）

- 想定ターゲット：21歳前後の大学生（地域は限定しない）。試験に向けた勉強を毎日30分のような計画で進めようとするが、急な課題や用事で崩れ、1〜2週間でやめてしまう人
- 提供価値：計画が崩れても、遅れた分を組み込み直す面倒な作業をしなくて済む
- 解決策：崩れたら、遅れた分の組み直しをAIが代わりにやり、新しい予定をスマホに届けるアプリ

## ② 素材あつめ（途中）

- 投稿先：TikTok
- 検索キーワード：「勉強計画 崩れる」
- TikTokでの探し方：検索 → フィルター → 並べ替えを「いいね数」、投稿日を「過去3か月」など
- 見るポイント：
  - おおよその再生数（いいね数）
  - 最初の1〜2秒で何を見せているか（文字、顔、手元、画面など）
  - 起承転結（課題 → 共感 → 理想の状態 → 解決策）それぞれで何を言っているか
  - うまいと感じた伝え方、すぐ飛ばしたくなった点

3. 文言を差し替えるだけで使える型（差し替え箇所を【】で示す）
4. この型で私のアプリを紹介するとき、最後の訴求をどこにどう入れるか
