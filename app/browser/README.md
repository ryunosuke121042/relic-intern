# ブラウザ版（デモ用）

`App.jsx` は、Supabaseなしでブラウザだけで動くデモ版です（Claudeのアーティファクトとして作成）。

完全版（リポジトリ直下）との違い：

- データはアーティファクトの保存領域（`window.storage`）に保存する
- AIはアーティファクトからClaude APIを直接呼ぶ。AIが失敗したときはルールで組み直す
- Web Push通知は送れないため、開いたときに組み直し案を表示する
- 完全版にない機能：昨日の予定をスワイプで記録する画面、今日の予定の追加、デモ用の「次の日へ」

`window.storage` とAPIキーなしのClaude API呼び出しは、Claudeのアーティファクトの中でだけ動きます。
